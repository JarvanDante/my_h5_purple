# my_h5_purple

内容站 H5 架子（Vue3 + Vite + Vant + Vue Router）。  
工程形态参考 `jh_h5`（手机框、底部导航、紫金主题），页面结构参考旧站首页：顶部分类 + 底栏五 Tab。

## 底栏

- 二次元 `/comic`
- 视频 `/video`
- 星球 `/planet`
- AI `/ai`
- 我的 `/me`

目前只有界面占位，未接接口。

## 本地启动

```bash
pnpm install
pnpm dev
```

默认 `http://127.0.0.1:5174`（避开 `jh_h5` 的 5173）。
